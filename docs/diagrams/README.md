# Diagrams

| File | What |
|---|---|
| `architecture_pictorial.py` | Generates the icon-based diagram (`../architecture-pictorial.png`) from a hand-placed layout. Needs `pip install playwright && playwright install chromium`. |
| `devsecops_pipeline.py` | Generates the DevSecOps pipeline picture (`../devsecops-pipeline.png`): security controls per stage, the trusted image path and the model supply chain. |
| `devsecops-pipeline.html` | Generated HTML for the pipeline picture. |
| `architecture-pictorial.html` | Generated HTML (icons embedded); open it in a browser to zoom without loss. |
| `icons/` | AWS Architecture Icons and project logos (Argo, Ray, Jupyter, Karpenter, OpenCost, External Secrets, Elastic, Grafana, Prometheus, Loki, Terraform, GitHub, Helm, FastAPI, Trivy, Kyverno, Falco, Open Policy Agent, OWASP ZAP, Checkov, AWS security services), [Simple Icons](https://simpleicons.org) (CC0) and [Lucide](https://lucide.dev) symbols (ISC). These are trademarks of their owners and are used only to identify those products. |
| `../architecture.svg` | Detailed, hand-editable diagram (`../architecture.png`). |
