# Diagrams

| File | What |
|---|---|
| `architecture_pictorial.py` | Generates the icon-based diagram (`../architecture-pictorial.png`) from a hand-placed layout. Needs `pip install playwright && playwright install chromium`. |
| `architecture-pictorial.html` | Generated HTML (icons embedded); open it in a browser to zoom without loss. |
| `icons/` | AWS Architecture Icons and project logos (Argo, Ray, Jupyter, Karpenter, OpenCost, External Secrets, Elastic, Grafana, Prometheus, Loki, Terraform, GitHub, Helm, FastAPI, Trivy). These are trademarks of their owners and are used only to identify those products. |
| `../architecture.svg` | Detailed, hand-editable diagram (`../architecture.png`). |
